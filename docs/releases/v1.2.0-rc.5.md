# Maverick v1.2.0-rc.5

RC.5 is an unpublished candidate with the existing protocol/SDK feature scope.
It updates `rustix` from 1.1.4 to 1.1.6 after the required CI dependency check
reported [RUSTSEC-2026-0486](https://github.com/RustSec/advisory-db/blob/main/crates/rustix/RUSTSEC-2026-0486.md).
The upstream fix addresses zero-length buffers in extended-file-attribute
functions. No first-party call to those affected functions was found; this is
a dependency-policy correction, not a claim of a demonstrated Maverick exploit.
The advisory is not ignored and no security check is weakened.

Only rustix's registry version/checksum changes in the root and H3 fixture
locks; existing unrelated dependency selections remain. Workspace packages use
the new candidate version because changed dependencies require fresh artifact,
SBOM, native rollback and independent replacement-review evidence. RC.4 files
and their historical records are preserved, not relabeled as RC.5 validation.

The source also includes [gated Stable tooling](../STABLE_RELEASE_TOOLING.md):
strict release classification, exact-commit Stable publication approval, full
H2/H3 package/SBOM verification, and private native Stable-format rehearsals.
A review found and corrected an isolated rehearsal lock rewrite that had
incorrectly changed the independent H3 fixture's 0.0.0 version. Locked offline
metadata now checks that fixture before packaging.

H2/H3 TCP/UDP, explicit UDP policy, new-session selection, protected H2,
authentication and configuration semantics remain unchanged. All applicable
local/CI, dependency, native artifact/SBOM, compatibility and pinned Beta.4
upgrade/rollback checks remain required for the exact RC.5 source and bytes.
Review and verification results belong to the associated Git/PR/Actions records.

Protocol and SDK functionality remain frozen. Field validation, real deployment,
release tags, setting Stable publication approval and publishing Releases remain
deferred. Rehearsal packages are not releasable Stable files. No Stable version
or production-readiness claim is published by this candidate preparation.
