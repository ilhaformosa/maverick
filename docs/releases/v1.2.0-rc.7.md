# Maverick v1.2.0-rc.7

RC.7 is the internal qualification candidate for 1.2.0. The project will use
it to check the fixes from the review of RC.6 before promoting the stable
build. The public RC.6 checkpoint remains available.

- A local SOCKS5 UDP association now opens its relay on the same IP family as
  its control connection, so clients connecting on IPv6 loopback can send UDP.
- The HTTP CONNECT listener enforces its 8 KiB header limit while preserving
  tunnel bytes received in the same read.
- The CLI's `user-smoke` and `bench-local` commands create their temporary TLS
  key with owner-only permissions on Unix and keep it outside the directory
  used to serve fallback pages. The local benchmark also reads replies while
  sending, allowing larger echo transfers to complete.
- Credential validation enforces the protocol's 512-byte limit during setup
  and detects duplicate active or previous IDs across server users.
  `gen-user` preserves YAML punctuation in names. `gen-config` checks both
  output names for existing files or links before writing the pair.
- Server validation rejects pre-authentication limits too small to admit an
  H2-only connection. The minimum is two slots for direct H2 and three for
  origin-protected H2. The default is 512.
- Fallback pages honor HTTP HEAD requests, and reverse-proxy fallback can
  connect to an IPv6 literal upstream. When an integrating client supplies
  initial TCP data with its open request, the server forwards those bytes in
  order after admission.
- The optional TUN dependency `heapless` is updated from 0.9.3 to 0.9.4 for
  reported memory-safety issues. The packaged CLI excludes the optional TUN
  engine. The local harness checks optional core features including the
  repaired Noise experiment. Package verification checks the reported carrier
  for both H2 and H3 smoke runs.

The candidate is intended for automated qualification. The maintainer deferred
field acceptance, operational rollback and the planned 72-hour soak for the
1.2.0 release. This decision applies only to 1.2.0.
