# Maverick v1.2.2

1.2.2 is a dependency maintenance release for the Maverick CLI. The
published 1.2.1 macOS and Linux packages include `url` 2.5.8. This patch
ships `url` 2.5.9, which fixes RUSTSEC-2026-0592, and its required
`form_urlencoded` 1.2.3. Maverick uses the URL crate for importing and
exporting profile URIs. Review of the CLI found no direct calls to the
affected origin accessors. [RustSec advisory](https://rustsec.org/advisories/RUSTSEC-2026-0592.html).

Use the archive, SHA-256 checksum and CycloneDX software bill of materials
for Apple Silicon macOS (`aarch64-apple-darwin`) or native Linux x86_64
(`x86_64-unknown-linux-gnu`). Verify the checksum and follow the included
`START_HERE.txt`. Existing 1.2.1 client and server configurations work with
1.2.2. Back up each program and its private YAML before upgrading. Stop the
service and stage the replacement executable in a fresh file before renaming
it over the old path. Use the same procedure to restore the saved program
and settings. [Deployment and rollback](https://github.com/ilhaformosa/maverick/blob/v1.2.2/docs/DEPLOYMENT.md).

Native qualification exercises both 1.2.1 and 1.2.0 against the candidate
on six loopback routes, covering both mixed client/server directions, upgrade
and restoration. Each phase checks TCP contents, EOF and independent UDP
replies. The tagged workflow publishes the qualified archives directly.
Real-network operation, provider interoperability and a 72-hour field soak
remain unverified. Maverick is experimental software.
