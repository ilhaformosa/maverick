# Maverick v1.2.4

Maverick 1.2.4 fixes profile import previews. With an output path, 1.2.3
could report that a link without a secret would be written even though the
actual import failed. A clipboard preview could also consume the link.

Run `maverick config-uri import --uri - --dry-run --output client.yaml`
and supply the private link on standard input. The preview checks the
credential and destination, hides the secret and leaves the file unwritten.
It rejects an occupied path or a missing parent directory. The actual
write still depends on permissions and available space. Omit `--output`
to inspect a link without a secret. Keep the summary private because it
includes the endpoint and credential ID.

To create the file, repeat the command without `--dry-run` and supply
the complete link again. With `--clipboard` in place of `--uri -`, a
preview or failed import leaves the link available. A successful file
import attempts to clear it. Clear a secret-bearing clipboard yourself
when you finish previewing. [Configuration reference](https://github.com/ilhaformosa/maverick/blob/v1.2.4/CONFIG.md#profile-uri-v1-sharing-and-parser-boundary).

Download the archive, SHA-256 checksum and CycloneDX dependency inventory
for your platform. Verify the checksum and follow `START_HERE.txt` in the
archive. Save each role's 1.2.3 executable and private YAML before
upgrading. To roll back, stop each role, restore its saved program and
configuration, restart it and verify TCP and UDP transfers.
[Upgrade and credential rotation](https://github.com/ilhaformosa/maverick/blob/v1.2.4/docs/DEPLOYMENT.md).

The first candidate archive passed 23/23 configuration checks on each
native platform, including preview failures, private file creation and
clipboard retention using simulated clipboard commands. The 1.2.3 and
1.2.4 executables both passed all four credential rotation stages. Against
published 1.2.3, all 30 TCP and UDP cases passed on each platform,
including both mixed directions and fresh transfers after restoring the
saved programs and private YAML. The release workflow takes its six files
from the successful qualification of the tagged main commit.
[macOS results](https://github.com/ilhaformosa/maverick/actions/runs/45907972889/job/140209261586) and [Linux results](https://github.com/ilhaformosa/maverick/actions/runs/45907972889/job/140209261547).

Maverick remains experimental. Real-network interoperability, operational
rollback and the 72-hour field soak remain unverified.
