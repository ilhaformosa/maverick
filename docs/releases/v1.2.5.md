# Maverick v1.2.5

Use `check-config --check-local` to find two common startup failures while
the existing process is still serving. Run the appropriate command with
the staged private YAML as the account that will start Maverick.

```sh
maverick check-config --kind client -c client.yaml --check-local
maverick check-config --kind server -c server.yaml --check-local
```

On macOS and Linux the check rejects a configuration file with any group
or other permission bits set. Restrict the file to its owner with `chmod 600`.
The client checks for a TCP overlap between SOCKS and HTTP CONNECT. H2
and dual servers check their main and metrics TCP listeners. Change the
conflicting address or port, or disable an unused optional listener.
Fixed H3 can share a port number between its UDP listener and TCP metrics.
The check opens no sockets. After restarting, verify readiness and a reply
from the target. [Configuration reference](https://github.com/ilhaformosa/maverick/blob/v1.2.5/CONFIG.md#check-local-cli-startup-settings-before-restarting).

Download the archive, SHA-256 checksum and CycloneDX dependency inventory
for your platform. Verify the checksum and follow `START_HERE.txt`. Save
each 1.2.4 executable and its private YAML before upgrading. To roll back,
stop both roles, restore the saved files and verify TCP and UDP transfers
after restart. [Deployment guide](https://github.com/ilhaformosa/maverick/blob/v1.2.5/docs/DEPLOYMENT.md).

On each native platform, the first 1.2.5 candidate passed 25/25 packaged
configuration checks. After correcting a group-readable file and overlapping
listeners, the client and server each restarted on their original port and
answered a SOCKS greeting or metrics request respectively. All 30 TCP and
UDP cases with published 1.2.4 passed, covering both mixed client/server
directions, upgrade and working transfers after restoration of the saved
programs and private YAML. The published files come from the qualified
tagged main commit. [macOS results](https://github.com/ilhaformosa/maverick/actions/runs/46077547949/job/140768756081) and [Linux results](https://github.com/ilhaformosa/maverick/actions/runs/46077547949/job/140768756126).

Maverick remains experimental. Real-network interoperability, operational
rollback and the 72-hour field soak remain unverified.
